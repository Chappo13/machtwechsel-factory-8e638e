1. Открываешь YouTube в браузере с **автопереводом** (правый клик → перевести на русский)
2. Ищешь по тегам выше
3. Сортировка: "За последний месяц" + сортировка по просмотрам
4. Кликаешь на видео с **>100K views за 30 дней**
5. Скидываешь URL мне → я через transcript_fetcher делаю наш sequel
