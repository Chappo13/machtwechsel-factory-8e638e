## 8. Выводы для дешёвого завода

1. В Tainy деньги уходят на озвучку и картинки, а не на сценарий (при подписке). Для Machtwechsel с одной озвучкой и без дубляжа ролик 12-15 минут по структуре Tainy стоит около $1.5-2.5 деньгами: озвучка 12-14 тыс. знаков (около $0.3 по прокси-ставке) + Deepgram $0.10 + картинки 40-90 штук ($0.4-0.9) + обложки $0.03-0.10. Это расчёт по ставкам из файлов, не измеренная цифра для Machtwechsel.
2. Главный рычаг экономии это бюджет иллюстраций по зонам (80% в первые 10 минут) и реюз пула после 17-й минуты, плюс график кодом вместо картинки там, где в озвучке есть число.
3. Если LLM идёт по подписке, сценарий бесплатен; если по API, заложить $3-4 на сценарий и $7-10 на ролик целиком (Opus на сценарий, Sonnet на остальное). Для экономии можно писать сценарий на Sonnet: Tainy держит Opus только для написания и правки (36% API-расходов).
4. Предпроверка денег на весь этап до первой траты (`budget.py`) и сохранение оплаченных ответов TTS (`.voicer_raw`) исключают двойные платежи.
5. Скрытые затраты, которые не видны в $: размер пакета до 0.5 ГБ на каждый ролик при дубляже, диск сервера (`cleanup_jobs` держит 3 последних), очередь озвучки.
