# Video build speedup — implementation checklist (loop #1)

Plan source: memory/video-build-speedup-plan.json. Goal: parallelize clip acquisition. Caps: render=2, ffmpeg=4, stock=2/provider.

RULES: implement one edit → py_compile (backend) / npm run build (frontend) → commit. Do NOT push/deploy (RED, interrupts running build) — stop & ask before deploy. Voiceover is preserved on redeploy (voiceover.mp3 + checkpoint.json on volume; resume skips TTS).
